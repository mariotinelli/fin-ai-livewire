# FinAI — Escopo Inicial do MVP

Fonte: texto fornecido pelo usuário em 13/11/2026. Formatação normalizada, conteúdo preservado.

## 1. Visão Geral

O FinAI é um sistema de controle financeiro pessoal que combina funcionalidades tradicionais de gestão financeira com um assistente de inteligência artificial.

O objetivo é permitir que o usuário organize suas finanças de maneira simples, utilizando tanto a interface do sistema quanto interações em linguagem natural com a IA.

## 2. Objetivo do MVP

Desenvolver uma primeira versão funcional que permita registrar, visualizar e consultar movimentações financeiras, incluindo uma integração básica com IA.

O projeto também tem como objetivo servir de ambiente prático para o estudo de engenharia de IA.

## 3. Funcionalidades

### 3.1. Dashboard Financeiro

- Visualizar saldo geral.
- Visualizar total de receitas e despesas do mês.
- Consultar movimentações recentes.

### 3.2. Gestão de Transações

- Cadastrar receitas e despesas.
- Editar e excluir transações.
- Associar transações a categorias.
- Consultar histórico de transações.

### 3.3. Categorias

- Disponibilizar categorias predefinidas.
- Classificar receitas e despesas por categoria.

### 3.4. Assistente Financeiro com IA

- Interagir com o usuário por meio de um chat.
- Registrar receitas e despesas a partir de mensagens.
- Identificar automaticamente informações como valor, descrição e categoria.
- Consultar informações financeiras registradas no sistema.
- Solicitar informações adicionais quando necessário.

## 4. Regras Básicas

- O usuário poderá registrar transações manualmente ou utilizando a IA.
- Todas as transações deverão ser persistidas no sistema.
- O dashboard deverá refletir as movimentações registradas.
- A IA deverá consultar dados reais do sistema, sem inventar informações financeiras.
- A IA deverá solicitar confirmação antes de registrar uma transação identificada por conversa.

## 5. Fora do Escopo do MVP

- Integração com bancos.
- Importação de extratos.
- Controle de cartões de crédito.
- Planejamento de metas financeiras.
- Relatórios avançados.
- Gestão financeira empresarial.
- Múltiplos agentes de IA.

## 6. Critérios de Sucesso

O MVP será considerado funcional quando o usuário conseguir:

1. Registrar receitas e despesas manualmente.
2. Visualizar sua situação financeira no dashboard.
3. Registrar uma transação conversando com a IA.
4. Perguntar à IA sobre suas movimentações financeiras e obter respostas baseadas nos dados cadastrados.

## 7. Evoluções Futuras

O projeto poderá evoluir para incluir análises financeiras inteligentes, automações, importação de documentos, recomendações personalizadas e funcionalidades voltadas a autônomos e pequenos negócios.
