# Aproveitar histórico sem migrar automaticamente

Leia documentos canônicos, arquivos históricos disponíveis, Git e remoto. JSON legado pode fornecer evidência de IDs, decisões e operações, mas não é requisito para o fluxo novo. Preserve originais, aprovações e caminhos; não crie aprovação retroativa nem converta automaticamente versões.

Concilie por servidor/projeto/pai/ID confirmado, não pela data mais nova. Dois arquivos para uma identidade ou conflito de aprovação exige revisão. Filha já publicada é consultada, não criada novamente. Operação incerta precisa de consulta antes de qualquer repetição.

Escreva resumo legível no documento responsável com fatos comprovados, referências às evidências antigas e pendências reais. Materialize task.md ausente somente após conferência de publicação completa. Reorganização de diretórios depende de solicitação/autorização específica e deve preservar referências, não eliminar fontes antigas.

**Concluído quando:** próximo passo seguro pode ser determinado sem motor antigo e nenhuma identidade/história foi inventada ou perdida.
