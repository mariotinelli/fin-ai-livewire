# Study discipline

Use a Study only when observable technical uncertainty prevents defining complete vertical slices. Formulate a question whose answer changes the breakdown, state the evidence or decision to deliver, and impose a readable effort bound. Open exploration, common preparation and partial implementation belong to ordinary slices.

The result must identify author, time and verifiable source. Treat it as evidence for a new proposal: reassess slices, coverage, estimates and dependencies with the result visible. Evidence does not change an approved revision; the resulting proposal passes ordinary approval again.

**Complete when:** question, expected delivery and bound are precise enough to verify completion; after execution, the attributed source-linked result appears explicitly in the new proposal.
